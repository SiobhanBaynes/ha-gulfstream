# Gulfstream Pool Heater

Control a **GulfStream** pool/spa heat pump (Compass / CaptouchWiFi Wi-Fi module)
from Home Assistant as a `climate` entity: current water temperature, target
setpoint, and on/off.

This is a **cloud** integration — the module has no local API — reproducing the
mobile app's calls to the vendor cloud. Set it up from the UI with your app
username and password.

See the [README](https://github.com/siobhanbaynes/ha-gulfstream) for
details and the reverse-engineered protocol notes.
